# Contribuir

1. Usa Node.js 22.13 o posterior y `npm ci`.
2. Crea una rama corta para un cambio concreto.
3. Mantén el cálculo musical y la composición como funciones independientes del DOM.
4. Añade pruebas para cambios de comportamiento, especialmente anclas, importación y exportación. Evita fixtures con canciones ajenas o información personal.
5. Ejecuta `npm test`, `npm run build` y `npm run test:e2e` con Vite activo.
6. Usa `npm run format` y describe el problema, el resultado y la validación en el PR.

Conserva las atribuciones de fuentes y datos. No incluyas credenciales, `node_modules`, compilaciones ni artefactos generados. Para informar de un fallo, indica navegador, pasos y un ejemplo mínimo de texto inventado que lo reproduzca.

La publicación como proyecto de código abierto y la licencia del código propio están pendientes de decisión del propietario.
